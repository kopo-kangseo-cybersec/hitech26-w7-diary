# 마음결 — 감정 일기

하루의 감정과 짧은 기록을 남기는 감정 일기입니다. 기록은 Supabase에 저장되어 같은 프로젝트를 사용하는 기기와 브라우저에서 확인할 수 있습니다.

## 소개

- 😊 기쁨, 😌 평온, 😢 슬픔, 😠 화남, 😰 불안 중 오늘의 감정을 선택해 기록합니다.
- 기록을 최신순으로 확인하고, 전체 또는 감정별로 필터링할 수 있습니다.
- 기록을 추가하거나 삭제할 수 있으며, 로딩·저장 중·오류·빈 목록 상태를 표시합니다.
- 데스크톱과 모바일 화면에 맞춰 레이아웃이 조정됩니다.

## 어떻게 만들었나요

Vite와 React로 화면을 만들고, Copilot Plan 모드에서 요구사항과 파일 구조를 정리한 뒤 Agent로 구현했습니다. Supabase JavaScript 클라이언트로 데이터베이스에 연결하고, Tailwind CSS 4의 Vite 플러그인을 설정했습니다.

## 데이터는 어디에 저장되나요

Supabase의 `public.diaries` 테이블에 저장합니다.

| 컬럼 | 형식 | 설명 |
|---|---|---|
| `id` | `bigint` | 데이터베이스가 자동 생성하는 식별자 |
| `content` | `text` | 일기 내용 |
| `emotion` | `text` | `joy`, `calm`, `sad`, `angry`, `anxious` 중 하나 |
| `created_at` | `timestamptz` | 데이터베이스가 자동 생성하는 작성 시각 |

6주차 To-Do의 `localStorage` 저장과 달리, 이 앱은 서버의 같은 테이블을 조회합니다. 따라서 같은 Supabase 프로젝트에 연결한 다른 기기나 브라우저에서도 같은 기록을 볼 수 있습니다. 현재는 로그인 기능이 없어 모든 방문자가 동일한 기록 목록을 공유합니다.

## 보안에서 확인한 것

- 프로젝트 URL과 Publishable Key는 로컬 `.env.local`에 두며, 이 파일은 `.gitignore`에서 제외됩니다. 배포할 때는 Netlify의 환경변수 설정에도 같은 변수명을 등록해야 합니다.
- `VITE_` 환경변수는 브라우저 코드에 포함되므로 개발자 도구에서 Publishable Key를 확인할 수 있습니다. 이 키는 브라우저에서 쓰도록 공개된 키이지 비밀 키가 아닙니다. `sb_secret_...` 또는 `service_role` 키는 절대 클라이언트에 넣지 않습니다.
- 실제 접근 제어는 Supabase의 RLS 정책이 담당합니다. [`guide.md`](./guide.md)에 안내된 실습용 RLS SQL은 익명 방문자 누구나 기록을 읽고, 추가하고, 삭제할 수 있도록 허용합니다. 이 정책을 그대로 사용하면 비공개 일기장이 아니며, 다른 방문자가 기록을 보거나 지울 수 있습니다. 개인용 서비스로 운영하려면 인증을 추가하고 사용자별 정책으로 제한해야 합니다.

## 실행 방법

### 로컬 실행

1. Supabase 프로젝트와 `diaries` 테이블을 준비합니다. 테이블 및 RLS 설정은 [`guide.md`](./guide.md)를 참고하세요.
2. 저장소 루트에서 `.env.example`을 복사해 `.env.local`을 만들고 실제 프로젝트 값으로 채웁니다.

   ```env
   VITE_SUPABASE_URL=https://<프로젝트-id>.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_<키>
   ```

3. 의존성을 설치하고 개발 서버를 실행합니다.

   ```bash
   npm install
   npm run dev
   ```

4. 검사 및 프로덕션 빌드:

   ```bash
   npm run lint
   npm run build
   ```

### 배포

현재 배포 URL은 없습니다. Netlify에 배포할 때 빌드 명령은 `npm run build`, 게시 디렉터리는 `dist`로 설정하고, 위의 두 Supabase 환경변수를 Netlify에도 등록하세요. 배포가 완료되면 이곳에 사이트 URL을 추가합니다.

## 커스터마이징한 부분

- 앱 이름과 시각 스타일을 감정 일기 서비스에 맞게 **마음결**로 구성했습니다.
- 목록에 한국어 날짜·시간, 감정 표시, 전체 기록 수, 감정 필터를 추가했습니다.
- 저장 버튼은 필수 입력 전 비활성화하고, 중복 저장을 방지합니다. 삭제 중에도 중복 요청을 막습니다.
- 로딩 표시, 감정별 빈 상태, 오류 메시지, 모바일 대응 레이아웃을 추가했습니다.
- Supabase 클라이언트 생성은 `src/lib/supabase.js` 한 곳에 두고, 데이터 조회·추가·삭제는 `src/api/diaries.js`로 분리했습니다.
